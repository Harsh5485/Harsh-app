# Harsh - Movie & Series Streaming

![Harsh Banner](https://via.placeholder.com/1200x600?text=Harsh+Streaming+App)

Harsh is a modern Android application designed for streaming movies and series with ease. It features fast streaming capabilities and seamless integration with Telegram and Stremio for an enhanced viewing experience.

## 🚀 Features

- **Fast Streaming**: Optimized video playback with minimal buffering.
- **Telegram & Stremio Integration**: Easily access and stream content from your favorite platforms.
- **Modern UI**: Built with Jetpack Compose following Material 3 design guidelines.
- **Adaptive Codecs**: Smart hardware/software decoding fallback for compatibility with all devices.
- **Clean Interface**: Intuitive navigation for movies, series, and live content.

## 🛠️ Built With

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Modern toolkit for building native UI.
- **ExoPlayer**: For high-performance video playback.
- **Material 3**: Latest design system from Google.
- **Retrofit & OkHttp**: For network operations.
